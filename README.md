# Multi-Class Waste Classification Project

Waste sorting is a critical challenge in modern waste management. Automating this process can significantly reduce human intervention, improving efficiency, and hygiene. In this project, we build a CNN model to classify waste into Plastic, Metal, Paper, and Miscellaneous categories.

The data directory contains images of waste items collected from waste plants, and scrapeyards in Goa, India. 
This dataset comprises 16,281 images of waste items categorized into four distinct classes: 
Plastic: 6,807 images 
Paper: 2,767 images 
Metal: 2,283 images 
Miscellaneous: 4,424 images.

The data was manually collected and aggregated. Most waste items have multiple images captured with different orientations.
